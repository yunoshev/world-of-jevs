# World of Jevs

Public project site and generated NPC behavior catalog.

The catalog currently reports seven accepted focused Deadmines encounters and
two bounded trash scenes: the 26-static post-Rhahk scene and the 18-static
post-Sneed workshop fringe. These are paired strict physical-scene results,
not a claim of full-instance, full-route, every trash pack, or every hostile
spawn acceptance; literal stock-speech parity is not measured.

The working server repository remains private. Public AzerothCore integration
patches will be published here separately after their interfaces stabilize.
