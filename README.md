# World of Jevs

Public project site and generated NPC behavior catalog.

The catalog currently reports 7/7 accepted focused Deadmines encounters. Its
23 static post-Rhahk bindings are configured-only, not physically or strictly
accepted. This is not a claim of full-instance, full-route, trash, or 149/202
hostile-spawn acceptance, and literal stock-speech parity is not measured.

The working server repository remains private. Public AzerothCore integration
patches will be published here separately after their interfaces stabilize.
